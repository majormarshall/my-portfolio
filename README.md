## ⚙️ Setup & Deployment

### Static Hosting (GitHub Pages / Netlify)
1. Fork or clone this repository
2. Push to your GitHub account
3. Enable **GitHub Pages** from the repository Settings → Pages → deploy from `main` branch

### PHP Hosting (cPanel / Shared Host)
1. Upload all files to your `public_html` directory via cPanel File Manager or FTP
2. The contact form at `forms/contact.php` requires a PHP-capable server
3. Edit `forms/contact.php` to configure your SMTP credentials if needed
